# Sammi Developer Portfolio

Create a Premium Portfolio Website for a Frontend & Full-Stack Developer



Design and build a complete, polished, modern portfolio website for a frontend and full-stack developer named Sammi.



This should be a professional portfolio intended for recruiters, hiring managers and software development teams evaluating candidates for frontend and junior full-stack developer positions.



The website must communicate technical competence, product thinking, attention to detail and the ability to build complete web applications.



Do not create a generic developer portfolio template. Approach this as a senior UX/UI designer and experienced frontend engineer.



Build the complete website in one implementation. Do not stop at a hero section or a wireframe.



⸻



1. Design Direction & Visual Identity



Overall direction



Create a light, modern, premium and minimal design inspired by high-quality SaaS products, contemporary digital agencies and well-designed editorial websites.



The portfolio should feel:



Professional and confident.

Modern and technically sophisticated.

Clean, spacious and easy to navigate.

Thoughtfully designed rather than overly decorative.

Personal without looking informal.

Visually interesting without unnecessary effects.



Important: Do not use a predominantly dark design.



The website should primarily use a light colour palette.



Colour palette



Use a refined and restrained palette:



Main background: warm off-white (#F8F9FB or similar).

Secondary section backgrounds: very light cool grey (#F0F2F5).

Card backgrounds: white (#FFFFFF).

Primary text: dark charcoal (#20242C).

Secondary text: muted grey (#697386).

Accent colour: sophisticated blue-violet (#6558D3 or similar).

Borders: subtle light grey (#E5E8EF).



Use the accent colour selectively for buttons, links, small highlights and interactive elements.



Avoid excessive gradients, neon colours, glowing effects, strong shadows and unnecessary decorative elements.



A dark section can be used sparingly if it creates a meaningful contrast, but the overall website must remain light.



Typography



Use Manrope or Inter.



Typography should have:



Large, confident hero heading.

Clear visual hierarchy.

Comfortable line height.

Readable body text.

Consistent heading sizes.

Carefully controlled text widths.



Avoid excessively large headings that consume too much screen space.



Layout



Use:



Generous whitespace.

Consistent spacing.

A centred content container with a sensible maximum width.

Clear section separation.

Subtle borders and restrained shadows.

Consistent corner radii.

A responsive grid.



The design should feel carefully art-directed, not like a collection of standard UI components.
